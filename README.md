# rayne.nvim

Tooling for using nvim for [Rayne](https://github.com/Überpixel/Rayne) projects.

## Features

- Generate project
- Build project
- Launch project
- Attach lldb to project
- Run and debug Android builds
- Update compile commands in the background

## Usage

Example usage for `lazy.nvim`.

```lua
return {
	"twhlynch/rayne.nvim",
	opts = {},
}
```
